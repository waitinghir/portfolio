# Tim's AI Portfolio Blog

Personal portfolio showcasing AI projects built through human-AI collaboration.

🔗 **Live site:** [https://waitinghir.github.io/portfolio/](https://waitinghir.github.io/portfolio/)

## Features

- Bilingual support (EN / 繁體中文) with language toggle
- Dark tech-themed design
- Static HTML — no frameworks, no build step

## Projects

1. **新春大作戰** (Lunar New Year Challenge) — Three-stage mobile web game blending Lunar New Year culture with gameplay
2. **日文知識王** (Nihongo Quiz King) — 1v1 Japanese vocabulary quiz app, shipped to the App Store
   - v1.0 → v1.1: From zero to App Store
   - v1.2 → v1.3: Cloud architecture and N3 expansion
   - v1.4 → v1.5.1: Real word lists, a rival, and a backend
   - v1.5.2 → v1.6.3: Quality as a system
3. **飛行的回憶** (Memories of Flight) — Narrative game where mechanics are metaphors for loss and memory
4. **用 AI 把這個網站雙語化** (Bilingual-izing This Site with AI) — A meta case study
5. **那個騙了我 27 天的求職監控系統** (The Job Monitor That Lied for 27 Days) — A debugging detective story

## Tech

Single-file static HTML/CSS/JS, hosted on GitHub Pages. Noto Sans TC for Chinese typography.
