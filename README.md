# Tim's AI Portfolio Blog

Personal portfolio showcasing AI projects built through human-AI collaboration.

🔗 **Live site:** [https://waitinghir.github.io/portfolio/](https://waitinghir.github.io/portfolio/)

## Features

- Bilingual (EN / 繁體中文) with a language toggle that carries across pages
- Multi-page: every project and article has its own URL, with breadcrumbs
- Material 3 inspired design, light and dark (follows the system setting)
- Static HTML on GitHub Pages; pages are generated by a small script and committed

## Projects

1. **日文知識王** (Nihongo Quiz King) — 1v1 Japanese vocabulary quiz app, shipped to the App Store
   - v1.0 → v1.5.1: From zero to an app people use — five decisions
   - v1.5.2 → v1.6.3: Test the reviewer before you trust it
   - v1.6.4 → v1.7.0: Scale needs a process first
   - v1.6.4 → v1.8.0: It wasn't the AI, it was the clock (retention, work in progress)
2. **那個騙了我 27 天的求職監控系統** (The Job Monitor That Lied for 27 Days) — A debugging detective story
3. **新春大作戰** (Lunar New Year Challenge) — Game feel is a spec: turning "it feels wrong" into feedback AI can act on
4. **飛行的回憶** (Memories of Flight) — Narrative game where mechanics are metaphors for loss and memory
5. **這個作品集是怎麼寫出來的** (How This Portfolio Gets Written) — AI drafts, I own the judgment

## Structure

```
index.html                 home (generated)
projects/**/index.html     project and article pages (generated)
assets/site.css, site.js   shared styles and language toggle
images/                    screenshots
src/site.json              home cards, About, project page data
src/content/*.html         article bodies (EN and ZH spans)
tools/build.py             generator: python3 tools/build.py
```

To change content, edit `src/`, run `python3 tools/build.py`, and commit both the source and the generated pages.
