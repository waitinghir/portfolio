# Claude notes

Before doing any work in this repo, get the private repo `waitinghir/portfolio-notes`
(in a cloud session, attach it with `add_repo`; locally, `git clone` it) and read its `MEMORY.md`.

If you can't access it, stop and tell the user. Don't change content without those notes.

Pages are generated: edit `src/` (article bodies in `src/content/`, everything else in `src/site.json` or `tools/build.py`), run `python3 tools/build.py`, and commit both. Don't hand-edit the generated `index.html` files.
